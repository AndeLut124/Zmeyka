# Змейка на Python (pgzero)

Классическая игра "Змейка", написанная на Python с использованием библиотеки pgzero.

## Как запустить

1. Установите Python (если еще не установлен).
2. Установите библиотеку pgzero:
   pip install pgzero
3. Скачайте файлы игры.
4. Запустите файл `main.py`.

## Управление
- Стрелки на клавиатуре для движения.
- Собирайте яблоки, чтобы набрать очки.
